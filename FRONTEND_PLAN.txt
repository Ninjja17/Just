Frontend Plan (functional UI first)

Goal: Make all existing frontend pages and buttons fully functional against the current API.

Phase 1: Core CRUD UI
1) Skills
   - List skills with basic fields
   - Create skill modal/form
   - Edit skill modal/form
   - Delete skill action with confirm
   - Empty/loading/error states
2) Sessions
   - List sessions (default: all sessions)
   - Create session (manual entry)
   - Edit session
   - Delete session
   - Start/stop timer actions
   - Optional filter by skill
3) Goals
   - List goals
   - Create goal
   - Edit goal
   - Delete goal
   - Empty/loading/error states

Phase 2: Analytics and Social
4) Analytics
   - Overview cards (total skills/hours/progress)

5) Social

   - Follow/unfollow

   - Feed

Phase 3: UX polish and navigation
6) Auth flow UX

7) Consistency

   - Toast success/failure patterns
8) Verify navigation
